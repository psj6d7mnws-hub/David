MY RESET v2.1 — iPhone 16 layout update
=====================================

変更点：
 1. iPhone 16のダイナミックアイランド／ステータスバーに重ならないように、
    画面上部の余白をセーフエリア分確保するように変更。
 2. カレンダーの「月・週・日」表示がスマホ幅からはみ出さないよう修正。
 3. 下部タブから「筋トレ」「予定（カレンダー）」を非表示にして、6つのタブに整理。
    （ホーム・勉強・成長・目標・健康・設定）
 4. カレンダーと筋トレログは削除していません。
    ホーム画面「よく使うツール」のボタンから、従来どおり利用できます。
 5. オフラインキャッシュの識別名を更新し、PWA更新の反映を改善。

継続する機能：
  XP、レベル、RPGキャラ、称号、クエスト、勉強、筋トレ履歴、長期目標、
  カレンダーと予定、健康（体重・睡眠・食事）、分析、バックアップ／復元。

GitHub Pagesで更新する手順：
 0. 旧版アプリの「設定」でバックアップJSONを作成して安全な場所に保存。
 1. GitHubの my-reset リポジトリを開く。
 2. ZIPを展開し、index.htmlなど7つのファイルがあることを確認。
 3. index.html、upgrade.js、sw.js、README.txt と
    manifest.webmanifest、2つのアイコンを、リポジトリの一番上に置いて更新。
    ※ 以前のファイルを同名で置き換えること。ディレクトリを1段増やさない。
 4. GitHub Pagesのデプロイ完了後、iPhoneでホーム画面のアプリを開き直す。
    古い画面のままならSafariで公開URLを再読み込みしてから開き直す。
    PWAのキャッシュにより反映に時間差が出ることがあります。

既存データとの互換性：
  localStorageの保存キー「my-reset-v1」とデータ構造は変更していません。
  同じ公開URL／保存領域で更新すれば既存の記録は通常維持されます。
  ただしホーム画面WebアプリとSafariで保存領域が異なるケースがあります。
  定期的なJSONバックアップを強く推奨します。

プライバシー：
  アプリのコードはGitHub Pages上に公開されますが、端末内の記録は通常公開されません。
  ログイン機能・クラウド同期機能はありません。
